# Data dictionary — Designing Your Digital Teammate exports

Schema version **1.1** · workshop version **2.0.0**
(1.0 pilot files lack the fields marked *new in 1.1*; `tools/collate.py`
stacks both versions and leaves missing fields empty.)

## Files

| File | Origin | Contents |
|---|---|---|
| `team_<code>.json` | downloaded by each team (Part 4) | Canonical record — everything below in one nested JSON |
| `summary_<code>.md` | optional team download; also regenerated by collate | Human-readable rendering of the same data |
| `members.csv`, `teams.csv`, `summaries/` | produced by `tools/collate.py` from a folder of team JSONs | Stacked analysis tables |

```
python3 tools/collate.py data/                 # → data/collated/
python3 tools/collate.py data/ --exclude-demo  # drop ?demo=1 exports
```

## Identifiers

- `team_code` — generated code identifying the team; the only linkage key.
- `member_id` — `M1`…`Mn`, the member's number within the team. Members use
  `team_code` + `member_id` in the follow-up Qualtrics survey.
- No names or other personal identifiers are collected anywhere.
- `demo` — `true` when produced from `?demo=1` sample data; exclude from analysis.

## Members (`members` array / `members.csv`)

| Column | Meaning |
|---|---|
| `type` | Four-letter 16Personalities type, e.g. `INTJ` |
| `type_variant` | Type incl. identity suffix (`INTJ-A`/`INTJ-T`), derived from `identity_turbulent_pct` (>50 → `-T`) |
| `role_group` | Analysts / Diplomats / Sentinels / Explorers |
| `energy_extraverted_pct` | Energy: Introverted (0) … Extraverted (100) |
| `mind_intuitive_pct` | Mind: Observant (0) … Intuitive (100) |
| `nature_feeling_pct` | Nature: Thinking (0) … Feeling (100) |
| `tactics_prospecting_pct` | Tactics: Judging (0) … Prospecting (100) |
| `identity_turbulent_pct` | Identity: Assertive (0) … Turbulent (100) |

All `*_pct` columns hold a 0–100 position named after the **right** pole;
the left-pole share is the complement. `energy_extraverted_pct = 28` means
the member reported "72% Introverted". 50 = not set / neutral.

## Team record (`team_<code>.json` / one row of `teams.csv`)

| Field | Meaning |
|---|---|
| `schema_version`, `workshop_version`, `exported_at`, `team_size`, `n_members` | Provenance and headcount |
| `role_group_counts`, `absent_role_groups` | Composition summary (counts per group; groups with zero members) |
| `part1_prediction` | *new in 1.1* — reserved for the Part 1 prediction step; currently always `null` (feature deferred) |
| `part1_interpretation` | *new in 1.1* — the team's three recorded Part 1 discussions: `surprise` (surprising vs expected results), `spread` (spread vs clustering), `strengths` (strengths and gaps) |
| `design.gpt_name` … `design.b5_jargon` | Design-canvas answers B1–B5, free text as typed |
| `design.b2_ground_rules` | *new in 1.1* — the merged B2 answer (how to handle being wrong + what to refuse). In 1.1 files `b2_mistakes`/`b2_limits` are empty and retained for pilot continuity; in 1.0 files it's the reverse |
| `design.b6_primary_roles` | Ticked B6 ids: `gaps` \| `amplify` \| `struct` \| `debate` \| `empathy` \| `diverge` |
| `design.b6_primary_roles_labels`, `design.b6_other_role` | Human-readable B6 labels; optional free-text role |
| `evaluation.selected_topics` | Part 3 topics chosen (A mandatory + 2 of B/C/D) |
| `evaluation.topics[]` | All four topics, each: `selected`, `test_prompt`, `observation`, `interpretation`, `refinement`. Text may exist even when `selected=false` |
| `system_prompt` | Assembled prompt from the current design data. Since 1.1, B6 is **not** part of the assembled prompt |
| `design_v1`, `prompt_v1` | *new in 1.1* — B1–B5 answers and assembled prompt as they stood when the team first entered Part 3, i.e. the version deployed to EduGenAI and tested |
| `design_v2`, `prompt_v2` | *new in 1.1* — the same after the revision pass |
| `changed_fields` | *new in 1.1* — design fields differing between v1 and v2 (export names, e.g. `b1_role`); empty when the team declined to revise |
| `no_change_rationale` | *new in 1.1* — the team's one-line reason when they reviewed and kept the prompt; empty otherwise |

In `teams.csv`, nested fields flatten to: `part1_surprise/spread/strengths`,
`eval_<a-d>_*`, `v1_<field>`/`v2_<field>`, `changed_fields` (`;`-joined),
`n_changed_fields`.

## R quickstart

```r
library(tidyverse)
# after: python3 tools/collate.py data/
members <- read_csv("data/collated/members.csv",
                    col_types = cols(team_code = "c", member_id = "c"))
teams   <- read_csv("data/collated/teams.csv",
                    col_types = cols(.default = "c")) |>
  mutate(across(c(team_size, n_members, starts_with("count_"),
                  n_changed_fields), as.integer))
```
